# Override: рабочее приложение «СтройКонтроль» (приоритетнее MASTER.md)

MASTER.md сгенерирован как тёмная glass-тема и не используется. Источник истины — `frontend/src/index.css`.

## Стиль: сдержанный продуктовый UI 2020-х

Ориентир — рабочие продукты уровня Linear / Stripe Dashboard / сервисов Яндекса: современно и спокойно.
Две крайности, которых избегаем: «AI-шаблон» и «служебная система из 1990-х» (обе пользователь отверг).

- **Шрифт:** Golos Text Variable (self-hosted, родная кириллица), база 16px, заголовки 600.
- **Формы:** радиусы 6 / 8 / 10 / 12 / 16px; рамки 1px `#E3E7ED`; тень у карточек едва заметная, у hover и всплывающих слоёв — мягкая.
- **Цвета:** фон `#F6F7F9`, карточки белые, текст `#101828`, один акцент `#1F5FD1`, знак бренда — жёлтый `#F5B800` на тёмном.
  Остальной цвет — только статусы (ok / warn / danger / info) мягкими заливками меток.
- **Каркас:** десктоп — светлое боковое меню 260px (активный пункт — серая подложка + акцентная иконка) и верхняя панель
  (дата, время данных, колокольчик); телефон — верхняя панель + нижняя навигация с подписями.
- **Списки отклонений:** карточка-строка с фото слева (на телефоне — фото полосой сверху), метки, заголовок, метаданные, номер.
- **Движение:** только функциональное — диалог (сдвиг 16px + fade, 180 мс), тост, выпадающее меню, hover-переходы 150 мс.
  `useReducedMotion` соблюдается.

## Тёмная тема

Три режима: светлая, тёмная, «как на устройстве» (по умолчанию). Выбор хранится в `localStorage` (`sk-theme`),
применяется атрибутом `data-theme` на `<html>` ещё до отрисовки (скрипт в `index.html`), поэтому страница не мигает.
Переключатель — кнопка со значком в верхней панели (все экраны) и три кнопки в ряд на экране входа.

- **Только токены.** Тёмная тема — это переопределение тех же переменных в `:root[data-theme="dark"]`.
  В компонентах нет `dark:`-классов; появился новый цвет — добавляйте токен в обе темы.
- **Статусы: три роли цвета.** `ok / warn / danger` — текст и значки (в тёмной теме светлее);
  `*-solid` — заливка кнопок с белым текстом (одинакова в обеих темах); `*-bg / *-fg` — метки.
- **Акцент.** В тёмной теме синий светлее (`#6FA0F5`), поэтому на кнопках с ним тёмный текст (`on-primary`).
- **Контраст проверен расчётом:** текст ≥ 4.5:1, элементы управления ≥ 3:1 в обеих темах
  (скрипт проверки — в описании коммита «Тёмная тема»). Границы полей ввода — свой токен `--color-input`
  (3.1:1 на белом); остальные границы остались светлыми.
- **Меню действий.** Редкие действия в строке списка — в меню «⋯» (`ui/ActionMenu`), на виду одна главная кнопка.
  Клавиатура в меню — `useMenuKeys`: фокус на первом пункте, ↑↓ Home End, Escape возвращает фокус на кнопку.
- **Фото и рамки распознавания** от темы не зависят: кадр всегда на тёмной подложке, цвета техники — из справочника.
- `color-scheme` выставляется по теме, чтобы системные элементы (списки выбора, полосы прокрутки) были в тон.

## Формы (диалог «Добавить камеру» — образец)

- Подпись над полем, подсказка под полем, ошибка заменяет подсказку; поле связано с ними через `aria-describedby`, ошибка — `role="alert"`.
- Проверка — при уходе из поля и при отправке; до этого ошибки не показываются.
- Любая отправка: кнопка блокируется и показывает индикатор → затем результат словами (зелёная или красная панель, `aria-live`).
- Выбор из 2–3 вариантов — крупные карточки-переключатели с пояснением, а не выпадающий список.
- Опасное действие (удаление) — отдельный диалог с объяснением последствий.

## Состояния данных

Данные приходят с сервера: первый экран — «Загружаем данные…», при недоступном сервере — понятное сообщение и кнопка «Повторить».
Ошибки действий показываются всплывающим сообщением с жёлтым значком и держатся дольше успешных.

## Не делать (AI-клише)

Inter, цветные полосы слева у карточек, иконки в тонированных квадратах, hero-панели с сеткой/градиентом,
тёмно-синий сайдбар со скруглённой активной кнопкой, stagger/fade-up появления, ping/pulse, uppercase-микроподписи,
нумерация шагов в цветных кружках, чёрные кнопки в духе shadcn по умолчанию.

## Не делать (1990-е)

Системный шрифт как основной, углы 2–3px, серые полосы-заголовки у блоков, подчёркнутые ссылки вместо кнопок, полное отсутствие теней и переходов.

## Простота для неподготовленных пользователей (не ломать)

Тач-цели ≥ 44px, одна главная кнопка на экран, простые слова вместо терминов, «светофор» состояния объекта,
подтверждение каждого действия, вход по роли одним нажатием, фото в каждом сообщении об отклонении.
